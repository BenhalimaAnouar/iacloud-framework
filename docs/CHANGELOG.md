# Changelog

All notable changes to this project will be documented in this file.

The format follows Keep a Changelog.

---

## [1.0.0] - 2026-09-04

### Added

- Initial release of the IA-Cloud Adaptive Load Balancing Framework.
- AdaptiveBroker for CloudSim Plus.
- Automatic load balancing prediction using the IA-Cloud Prediction API.
- Support for 32 load balancing algorithms for prediction.
- Support for 10 load balancing algorithms for simulation.
- Dynamic runtime adaptation.
- API Key authentication.
- Configuration through `conf.properties`.
- Java examples.
- Developer documentation.

### Changed

- Improved policy initialization.
- Optimized API communication.

### Fixed

- Improved HTTP error handling.
- Added automatic fallback when the Prediction API is unavailable.

---
## [1.1.0] - Future
